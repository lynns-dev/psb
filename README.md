# Pretty Serious Brands (PSB)

Single-page site for PSB — a brand development, design, ecommerce and growth agency.

Plain static HTML/CSS/JS, no build step required.

## Run locally

Open `index.html` directly in a browser, or serve it:

```bash
npx serve .
```

## Deploy

Any static host works (Vercel, Netlify, GitHub Pages). No environment variables or backend needed — the onboarding form opens a pre-filled email to `lynns@prettyseriousbrands.com` on submit.

## Structure

- `index.html` — the entire site (hero, services, founder, approach, contact/onboarding form)
